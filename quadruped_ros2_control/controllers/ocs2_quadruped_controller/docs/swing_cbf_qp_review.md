# 摆动相 CBF-QP 理论核验与实现清理

## 算法定位

当前算法在固定 XY 路径上优化整段 B 样条的高度控制点，是参考轨迹的几何优化。
它没有以机器人加速度或力矩为变量，也没有 CLF 约束，不能称为双积分器 CLF-HOCBF 控制器。
一阶 CBF 可以用于约束这条可微参考曲线；问题在于不能把它直接解释为真实机器人的闭环安全保证。

标准 CBF 的前向不变性结论需要安全初值、相应的可微性与可行性条件，以及沿实际闭环运动持续满足的 CBF 条件。
参考轨迹满足条件，不能推出存在跟踪误差的足端也满足条件。
参见 [Ames 等，Control Barrier Function Based Quadratic Programs for Safety Critical Systems](https://arxiv.org/abs/1609.06408)。

## 1. 正确的一阶条件

设摆动时长为 T，相位 s=(t-t0)/T，B(s) 为样条基，c 为高度控制点，g(x,y) 为地形高程。
定义安全函数：

```text
d(s) = clearance * sin²(pi*s)
h(s) = B(s)c - g(x(s), y(s)) - d(s)
```

对于静态、可微地形，沿参考曲线有：

```text
dh/dt = [B'(s)c - grad(g)·(x'(s), y'(s)) - d'(s)] / T
d'(s) = pi * clearance * sin(2*pi*s)
```

因此 `dh/dt + gamma*h >= 0` 对应线性约束：

```text
[B' + gamma*T*B]c >= grad(g)·(x', y') + d' + gamma*T*(g+d)
```

原实现遗漏 d'，起跳与下降半段分别造成低估与高估约束要求。本次补齐此项。
原实现还用采样差分近似 B'，本次使用解析样条导数基，使矩阵约束与输出样条的速度一致。
地形梯度仍由 GridMap 估计，并不因此成为精确地形导数。

对于 h>0，增大 gamma 会降低 `dh/dt >= -gamma*h` 的要求，允许更快接近边界。
原先“gamma 越大越早抬腿”的参数注释没有普遍依据，已纠正。

## 2. 指数 CBF 与有限时间触地存在冲突

若从中段时刻 ta 开始 h(ta)>0，且一直满足上述 CBF，则比较原理给出：

```text
h(t) >= h(ta) * exp(-gamma*(t-ta)) > 0
```

所以不能在有限时间 tf 实现 h(tf)=0。
这说明不能简单把 CBF 扩展到整个摆动段。保留 `cbfStartPhase/cbfEndPhase`，在中段限制间隙衰减，
并在末段关闭 CBF、通过高度约束允许触地，是当前参数化下合理的处理。
但这也意味着 CBF 的不变性结论不能覆盖整个摆动过程。

## 3. 离散采样不等于连续时间安全

有限采样只能检查有限个位置。即使所有采样点的 h 和 CBF 残差非负，样点之间仍可能越界。
例如 h(s)=(s-0.5)²-0.01，取 gamma*T=5：在 s=0、1 时 h 与 h'+5h 都为正，
在 s=0.5 时 h 为负。
这里是样条配点问题，不能直接套用零阶保持控制器的采样安全定理；相关研究同样说明采样安全需要独立条件，
参见 [Breeden 等，Control Barrier Functions in Sampled-Data Systems](https://arxiv.org/abs/2103.03677)。

原实现进一步只选择少量代表约束，且优化后未复验所有 CBF。
本次删除代表点评分、间距筛选和条数上限，直接求解所有内部采样点的高度约束，以及窗口内的 CBF。
输出前统一检查这些线性约束的数值残差。没有加入新的约束类型或连续时间保护条件。

## 4. 实现中删除的逻辑

- 高度误差超过激活阈值才求解的分支：此前可以把存在安全间隙违反或 CBF 违反的原轨迹标为有效。
  开启 `useCbfUpdate` 后现在直接求解，不再区分“碰撞达到阈值”与“未达到阈值”。
- 根据控制点上下界预判不可达、禁用 CBF、删掉 CBF 后再次求解的降级链路。
  现在保留所配置的 CBF，求解失败即返回无效结果。
- 内部控制点世界高度上下界、动态扩界及参考投影。只保留起落足高度固定条件。
  原高度上限本就会被动态放大，不是可靠的物理可达性约束。
- 求解后按最大下降量、最大高度偏差和 jerk 比值拒绝轨迹。
  跟踪和平滑性由已有目标函数表达，不再用额外阈值覆盖求解结果。
- 允许端点误差 4 cm、时间误差 20 ms 且不跟踪地形更新的跨更新缓存。
  同一次更新内连续的非接触模式仍复用同一完整摆动段，避免重复求解；跨更新重新计算。
- 未使用的活动集扩张参数、地形 Hessian 接口与 epsilon，以及重复的采样点忽略设置。
- 头文件中已不对应实现的 CLF/HOCBF、加速度积分及绝对避碰描述。

同时清理配置加载项与 Cyberdog 的 task.info。
保留原有样条跟踪/平滑目标、抬升包络、首尾高度、CBF 相位窗口和 qpOASES 迭代预算。
保留高程查询的越界检查，避免 GridMap 的越界异常。

## 5. 本次未解决的模型限制

1. **真实足端与假设 XY 不一致**：QP 的 XY 用于查地形，MPC 接口只跟踪高度和垂向速度；实际足端可能走过不同地形。
2. **有限可达性**：只抬高 Z，不能横向绕障；没有关节、力矩、速度或加速度约束。删除限高阈值后，
   数学可行结果可能需要很高的控制点或很快的运动，不能据此认定机器人能执行。
3. **端点连续性**：固定起落足高度不等于固定端点速度和加速度。重拟合及重新优化也未保证与正在执行的曲线连续。
   本次没有通过增加端点导数约束或拼接约束扩展问题。
4. **高程模型限制**：2.5D 高程不能表达悬垂或完整足部碰撞体；台阶的真实不连续边界不满足光滑 CBF 假设。
   平滑高程与梯度估计也可能削弱真实障碍。当前查询缺层、越界、无效值仍退化为零高程/梯度，不能解释为已知平地。
5. **目标权重的采样依赖**：差分平滑项未按时间间隔归一化，抬升传播宽度也以采样点数计。
   本次维持已有目标与参数，改变采样数或摆动时长后不能直接假定行为一致。
6. **失败策略**：Planner 仍保留原始名义曲线作为求解失败时的输出。回退能维持参考接口运行，但不保证避障。
   本次没有新增停机、重规划或其他上层策略。

## 6. 验证范围与运行代价

- 没有执行构建、编译或仿真。

- 核验修正后的矩阵残差与直接计算的 `dh/dt + gamma*h` 一致。

  没有提高原有迭代预算，因此达到迭代上限仍可能返回失败。
