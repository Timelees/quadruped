## 本版修改

- QP 直接优化名义样条的修正量，首尾位置/速度修正固定为零；目标 Hessian 按最大对角元统一缩放，消除高阶导数代价造成的绝对高度目标大数抵消。
- 名义高度只作跟踪代价；删除上一版新增的名义高度硬下界。地形净空、CBF 与工作空间上下界保持硬约束。否则名义峰值超过工作空间时，即使存在更低且避障的轨迹也必然不可行。
- 所有 QP 失败路径输出状态或最差约束残差、剩余预算。没有增加删除 CBF、放宽工作空间或名义曲线回退。
- MPC 异常设置失败标记并停止运行标记，状态机转入现有 PASSIVE；避免永久使用旧策略。它是故障处理，不等于稳定爬楼策略。
- 足点可视化移到 MPC 求解结束之后执行，控制线程不再访问正在更新的 selector。
- 工作空间回调按值持有参考数据，避免异常后保留悬垂引用。

沿用 Eigen、qpOASES、现有状态机与可视化接口，未增加依赖、重试链或新的经验阈值。

## 再次运行：工作空间种子失败

运行已安装的 20:52 控制库（本轮未构建），排除两个键盘节点同时发布命令后，站立正常，切换 trot 立即报：

```
[GaitManager]: Switch to gait: trot
[Ocs2 MPC thread] Error : Swing horizontal path has no IK solution at its nominal leg height.
Switched from OCS2 State to passive
```

日志：`/tmp/cbf_diagnose.log`；ROS 原日志目录：`/tmp/cbf_diagnose_ros`。故障发生在 QP 求解之前，不能归因于 MPC 超时。

发现工作空间算法错误地要求新的 XY 在原姿态足端高度处可达；竖直线上存在其他可达高度时，这个前提仍可能失败。改为以关节限位内的名义姿态为种子，先用 2×3 Jacobian 最小范数 Newton 步求 XY（高度自由），然后以所得可达高度和姿态搜索竖直截面。未改变关节限位、CBF 或地形净空，未加入放宽约束和回退路径。真正 XY 求解失败时记录腿号、坐标和残差。另补上最后一次 Newton 更新后的残差检查，避免已收敛却返回失败。

沿用已有 Eigen QR、EndEffectorKinematics 和回归可执行文件。新增 `checkWorkspaceSeed()` 调用生产工作空间函数，覆盖原高度不可达但竖直截面可达，以及 XY 超出关节范围两种情况。C++ 用例未编译、未执行。

轻量 Pinocchio/SciPy 检查（Cyberdog 当前 URDF）：水平移动 0.15 m 时，固定原高度的最小 IK 残差为 0.005074 m；高度自由的 XY Newton 残差为 1.44e-6 m，关节在 URDF 限位内。该数值例证明旧前提不成立，并不证明本次 Gazebo 失败的具体足点可达；旧异常没有记录其坐标，新诊断将保留这些信息。

仿真在复现故障后已停止，未向前行走，也未验证稳定爬楼。修改后的控制库需用户编译后才能继续运行验证。

### 本轮源码修改

为有 IK 工作空间的摆动 QP 增加一个共享非负 CBF 导数松弛量。导数行除以 gamma*T，改为高度单位；其松弛代价与归一化后最高修正模式同尺度。地形净空、IK 上下界、端点位置速度仍为硬约束。无工作空间回调的原 CBF 回归路径仍保持硬 CBF。没有失败后重试、删除约束或回退名义轨迹。

这解决的是一个明确存在的模型冲突：几何安全且关节可达的下降轨迹，也可能不满足指定 CBF 间隙衰减率。松弛后只能声明离散几何净空满足，不能声明未松弛 CBF 不等式始终成立。日志增加 `cbf_height_slack`；失败时增加最小 workspace 上界与地形净空下界之差，便于下一轮判断物理高度交集是否为空。

沿用现有 Eigen、qpOASES 和生产回归可执行文件，不增加依赖或新配置项。增加窄工作空间回归，检查 CBF 松弛不会放宽地形和关节范围；保留真实障碍/工作空间无交集必须失败的用例。

独立 SciPy 数值用例：硬 CBF 问题不可行；同一硬几何约束加共享导数松弛后可行，最小几何残差 -2.08e-17 m，参考走廊最大偏差 0.004118 m（节点间线性工作空间插值存在约 0.000118 m 差异）。这是数学验证，不替代生产 qpOASES 或新源码仿真。
