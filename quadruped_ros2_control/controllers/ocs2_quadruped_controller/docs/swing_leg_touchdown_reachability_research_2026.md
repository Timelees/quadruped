# 四足摆动腿避碰与触地可达性的联合规划

截至 2026 年 11 月 9 日的专题调研与 Cyberdog/OCS2 算法设计。

## 摘要

本报告比较三类工作：把腿部几何约束降到足端空间的规划，具有到达时间和终端速度要求的有限时域可达性，以及在非凸走廊间传播运动状态的低维规划。前人已经分别实现腿部碰撞降维、带加速度界的走廊传播、接触时序优化和凸走廊内的样条优化。结合方案的研究机会在于：**将整条摆动腿几何产生的多个高度分支保留到终端可达性递推中，由触地状态反过来决定可选的几何分支，再提取低维凸轨迹。** 本报告给出一条实现路径、一项离散模型下可证明的性质，以及区分算法贡献与普通终端约束 QP 的实验。

## 1. 研究问题与检索范围

- **RQ1** 既有工作怎样把腿部碰撞映射到足端空间？已有二维降维与拟议的一维高度切片有何重叠？
- **RQ2** 在给定时间和速度下安全触地，已有研究做到哪一层？固定路径可达性、时空走廊和 CBF 各自覆盖什么？
- **RQ3** 两条路线联立后，什么能构成独立方法贡献？哪些实验可能推翻该判断？

从三条线索独立检索，分别使用 `swing leg collision inverse kinematics foothold reachability visibility graph`、`touchdown swing foot reach-avoid terminal velocity viability`、`fixed-path acceleration bounded trajectory PVT TOPP-RA safe interval convex corridor`，用 KCFRC、SIPP-IP、PVT、GCS 等方法名和参考文献继续回查。纳入足式机器人近邻及能直接反驳宽泛创新声明的其他机器人规划工作。对约束、算法和实验以作者原文为准，核对期刊和会议记录，预印本单列。检索针对本方案，数据库收录和中英文关键词均可能有遗漏，结论限定为检索所见。上一次调查中的实现和其他避障工作见[基础调研](swing_obstacle_avoidance_research_2026.md)。

## 3. 联合算法的建议定义

### 3.1 几何集合保留上下界、分支和接触例外

输入为机身预测 $b(t)$、同一坐标系下的足端水平参考 $p_{xy}(t)$、指定落脚点与触地截止时间。对每个可追踪的 IK 分支 $m$，令 $q_m(t,z)=\mathrm{IK}_m(b(t),p_{xy}(t),z)$。检查关节位置和足、胫、膝的碰撞距离，构造每个时刻的保守高度集合

```text
Z(t,m) = ⋃ᵣ [ℓᵣ(t,m), uᵣ(t,m)] .
```

只在指定足底区域和允许触地的时刻放开相应接触几何，胫膝仍受障碍约束。优先固定 Cyberdog 的正常 IK 分支。若未来允许切换，需验证关节构型连续可达，不能因足端位置相同而连边。需要保留区间的上下界与空洞：把两个分离区间做凸包会把中间碰撞区域重新标成可行。离线密采可用于找现象，在线原型应基于区间细分和保守距离界给出内近似，把未验证区间记为未知。

**高度区间分裂的解析例子。** 取矢状面等长两连杆，每段长 1，髋坐标 (0,2)，足端水平坐标固定为 0.3。固定前弯 IK 分支，足高分别取 0.05、1.00、1.90 时，膝的水平坐标约为 0.312、0.967、0.462。若有一根位于水平坐标 [0.79,0.81]、顶高为 2 的地面立柱，细连杆模型在中间高度穿过柱体，而在两个外侧高度避开。该例证明了固定 IK 分支和单值地面几何也可能产生不连通的足高区间，实际 Cyberdog 上的出现频率和宽度仍需测量。

### 3.2 终端条件在选择分支之前进入递推

取 $x=(z,v)$，控制量为竖向加速度，基础模型可按固定步长假定分段恒定加速度。令 $G_N$ 是指定触地位置、允许的接近速度、合法接触和末端关节构型的集合。若使用世界系竖向速度，要说明何时能近似触地法向速度。一般应使用 $v_n=n^T(\dot x_f,\dot y_f,v)$。从 $G_N$ 逐步向后构造 $K_i$：

```text
K_N = G_N
K_i = { x ∈ D_i : ∃ u ∈ U_i(x),
                    x(τ) 在当前区间持续满足安全条件，
                    F_i(x,u) ∈ K_{i+1} } .
```

其中 $D_i$ 由整腿安全高度分支和局部状态界构成，$U_i(x)$ 含加速度界及经验证的约束近似。若每条候选边的运动学、区间约束及离散动态均用凸线性关系保守表示，每个后继多面体的前驱可写成线性可行域的投影。沿分支分别保存多面体并集。在相同离散模式、相位和未来约束下，被另一集合包含的分量可从**可行性**表示中删除，优化代价仍需另行处理。最坏情况下分支数会增长。删减和超时属于工程预算，应报告漏掉的可行分支。

**具体的联合效应。** 当前离触地还剩 0.2 s，足端高度都是 0.06 m，假设加速度幅值不超过 2 m/s²，目标高度是 0，允许竖向接触速度为 [−0.3, 0] m/s。若初速度为 −0.4 m/s，用 +1 m/s² 可在终点得到 $z=0, v=-0.2$。若初速度为 +0.2 m/s，即使用 −2 m/s² 直至终点，最低终点高度仍为 0.06 m。两者可能落在同一个几何高度区间，只有第一种状态能在时限内到达。这个解析例子说明单用高度区间或当前净空判断会丢失速度信息。真实验证还应设置两个几何通道，其中局部代价较低的通道将速度带入触地不可达区域。

### 3.3 与样条 QP 共用轨迹模型

在选定各段的凸分量后，可以将 $z=Bc$、$v=B'c/T$ 映射到相应的多面体约束。若要把前驱递推的**可行性**直接传递给轨迹生成器，递推与 QP 必须描述同一种段内运动。二阶的分段常加速度轨迹通常只保证位置和速度连续，与现有三次 B-spline 的跨段连续性条件有差异。可选两种方案：

1. **先用二阶模型筛选。** 通过回溯得到候选分支，随后由样条 QP 和独立区间检查确认。筛选通过属于候选信息，最终只有复验通过才能输出轨迹。
2. **统一三次段模型。** 在样条结点间用常 jerk，将状态扩展为 $(z,v,a)$。在固定步长下，离散转移对状态和 jerk 仿射，位置、速度、加速度均可用段内 Bernstein 系数表达。可在同一模型上递推并恢复连续至加速度的曲线。若高度走廊在段内有可靠的分段多项式上下界，对两者差值使用 Bernstein 非负充分条件，形成线性限制。需量化充分条件带来的可行域损失和额外计算量。[Bernstein 运算与界，BeBOT](https://doi.org/10.3390/s22051869)

若初态在保守离散 $K_i$ 内、环境与机身预测不变、每次选择的段满足同一约束且后继仍在 $K_{i+1}$，则可用归纳法证明存在一条满足模型约束并达到 $G_N$ 的后缀。若每段还通过连续安全检查，该命题可扩展到模型中的区间净空。实际机器人保证进一步需要可量化的机身、XY、地形及关节跟踪误差、有效执行能力和安全触地条件。更新地图会改变集合，旧计划的后缀性质需重新检查。稳健反馈版本可研究对扰动集合的鲁棒前驱，开环参考的误差管需另行验证。

**一个容易被审稿人指出的等价性。** 若全程只有一条凸走廊、初末状态固定、预测无更新，且直接 QP 已包含相同的动力学和全过程约束，向后可达集合只是对同一全时域可行域的投影，不能因此扩大可行域。这里直接 QP 是强基线。联合算法的潜在优势来自多分支剪枝、重复查询、执行中更新、约束预算和保守认证。

## 4. 创新性分级与最小可发表主张

| 实现层级 | 创新性判断 | 审稿时最可能被质疑的问题 |
|---|---|---|
| 连杆碰撞取一个足高下界，QP 固定触地高度和速度 | **低** | Bratta 已有连杆到足高的下界，Corbères 已有端点导数 QP |
| 选一个几何走廊，再向后检查能否按时触地 | **低到中** | KCFRC 的几何路径检验加普通终端约束 QP 已构成直接对照，失败后再枚举也可完成 |
| 保留多个安全高度分支，在分支选择之前传播触地可行状态，再提取与同一模型一致的轨迹 | **中等，有方法论文潜力** | Johnson–Hauser、TOPP-RA、SIMP 和 GCS 已覆盖大部分通用求解思想。需要证明足式特化能改善实际可行率或预算 |
| 在上一层基础上，对段内几何和动作可达性建立保守验证，并在板载闭环证明收益 | **中到较强，取决于证据** | 内近似会漏掉真实可行解。需要给出保守性、速度、地图扰动、切换行为，以及与同条件精确/高精度方法的对照 |

建议的主张为：**针对已知机身与水平足端预测，构造连杆感知的多分支摆足高度走廊，通过终端可达性裁剪几何分支，生成满足截止触地条件的低维轨迹。** 这里的通用数学基础是有限时域 reach–avoid，能形成贡献的是可验证的几何投影、分支保留与低预算实现。检索未核实有足式论文同时采用这一整套特化组合，无法由此推出优先权。

最具区分度的验证是：几何最优分支因末端速度或剩余时间无法落脚，另一分支可行；随截止时间或允许触地速度改变，算法预测的可行分支发生切换。若测试中几乎总是单区间、单通道，主张应缩为低维整腿避碰和触地可行性检查。

## 5. Cyberdog 实现顺序与证伪实验

### 5.1 接口与计算

- **离线检查几何现象。** 从 Cyberdog 的 URDF 碰撞几何和预测姿态构造足、胫、膝包络。以箱沿、台阶和悬出物为场景，先画相位–高度图。2.5D 高程可验证箱沿及可表达的地面障碍。悬垂和侧面碰撞应使用仿真真值或可靠的 3D 表示。地图未知按未知处理。
- **加入低维可达性。** 先使用固定 XY、固定摆时、正常 IK 分支和给定机身轨迹。检查不同起始速度、触地速度范围及箱沿位置能否改变走廊选择。之后再把运动学关系 $\dot q=q_t+q_zv$ 用于速度约束。保留关节速度、执行器扭矩和支撑稳定的独立检查。
- **打通执行链。** 当前工作树的 MPC 摆动接口只沿 Z 方向使用参考，且执行中可复用摆段。闭环要么明确跟踪用于认证的 XY，要么把实际 XY 和机身误差包含在几何裕量中。执行中更换地图或路径时，应先重验证余下摆段。 [MPC 接口](../src/interface/LeggedRobotPreComputation.cpp#L73) · [执行中复用逻辑](../src/interface/constraint/SwingTrajectoryPlanner.cpp#L269)

### 5.2 必须保留的对照

| 实验 | 必须包含的对照 | 主指标 |
|---|---|---|
| 几何投影 | 足端单侧下界、连杆单一上下界、连杆多区间；用独立几何查询复核 | 假安全、未知、保守拒绝，连杆最小距离，真实多分支出现率 |
| 终端条件的净贡献 | 几何分支选择 + 普通终端约束 QP，和使用同一约束的向后传播 + QP | 在有可行解时首次找对分支的比率，尝试分支数，端点偏差和尾延迟 |
| 离散可行性与剪枝 | 用相同多面体与轨迹模型构建无严格实时预算的枚举 QP 或混合整数可行性参考 | 首解时延、同模型下的漏解、预算用尽率，内近似造成的损失 |
| 实机收益 | 当前 CBF-QP、同预算整腿约束 QP、联合算法；固定落脚和步态 | 每百次摆动的足、胫、膝意外碰撞，触地时间与法向速度误差，整轮 MPC 的 P95/P99，任务中断原因 |

同模型下的参考求解可以识别分支剪枝是否漏解，独立几何/动力学回放才可检查模型近似。内近似找到的路径可在假设下认证；内近似为空时应报告“未认证可行”，只有在包含真实可行域的外近似也为空或得到针对原模型的充分证据时，才能判定不可行。将多分支场景与普通单分支场景分别报告，避免特殊场景的收益掩盖常规开销。

### 5.3 建议的早停条件

1. 若相位–高度图几乎从不出现可操作的替代分支，或者分支在地图与机身误差裕量下消失，先保留单走廊整腿 QP，停止投入复杂分支算法。
2. 若同条件直接终端 QP 或小规模枚举已达到同等成功率和尾延迟，向后集合可作为诊断工具，论文主贡献转到几何与连续认证。
3. 若仿真里触地成功主要依赖放宽不现实的竖向加速度，先收紧与关节动力学一致的界，再重新比较。

## 6. 研究问题的回答

- **RQ1** Bratta 已把固定姿态的膝胫采样点压成足高下界，KCFRC 已做 IK、碰撞感知的低维连通性。沿指定 XY 使用真实 IK 保留多个高度区间，是更具体的建模差异。
- **RQ2** 有限时域 reach–avoid、末速度的向后传播、时空通道选择和样条优化各有直接先例。仅替换固定相位 CBF 或增加一个触地终端约束，创新性有限。
- **RQ3** 最有希望的区别是让触地可达性改变所选的整腿避碰分支。用普通终端 QP 和同模型枚举作对照，再检验闭环收益。如果数据支持，可将其发展为面向四足摆动的低维几何–动态联合规划。
