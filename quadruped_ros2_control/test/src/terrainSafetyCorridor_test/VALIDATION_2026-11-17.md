# 验证记录（2026-11-17）

## 实现范围与工程选择

复用项目已有的五次 B-Spline 提取、MINVO 基、qpOASES、高程地图接口、ROS Marker 和包发现软链接方式。新增独立 ROS 包由任务明确要求；没有新增求解器或几何依赖。最小接入保留固定 XY / Z 控制点 QP，只在边界处提供完整三维 `Aq<=b` 接口；全 XYZ 路线搜索会改变成熟的摆动优化器结构，当前没有实现。在线性能有测量依据后，将反复的地图查询改为每次摆动的一份保守快照；恒成立常量行仅从求解矩阵消去，完整输出复核保留。

走廊实现从整次摆动的二维半空间/高度屏障改为分段三维凸多面体；几何边界、误差球收缩后的规划边界、数值预算分别记录。所有占据柱参与分离，包含地面、侧向及细薄障碍；未知地图不作为自由空间。

发现并修复了任务路径中的两个正确性问题：触地高程曾作为额外加数重复计入抬升地形；初始地形扫描在地图未知时曾向外抛出 `TerrainUnavailable`。现在触地高程是下界，未知扫描返回未求解结果，沿用规划器既有失败分支。

## ROS 发布与 Gazebo

独立场景实际收到 98 个 marker，其中 64 个几何/规划线框、3072 个线框点；地图分辨率 0.02 m，坐标系 map。数据来自 ROS 订阅，见 `data/ros_topic_probe.json`。

在线配置 `corridorContactPhase=0.25`，即中间 50% 摆动采用完整 2 cm 误差球。独立几何测试是 `0.10`。这个区分是显式的接触模式边界，不是整段摆动的安全证书。

| 记录 | 结果 | 可据此说明 |
|---|---|---|
| `runtime_probe.json`，初轮 phase=0.10 | 侧翻；163 次非空走廊 | 早期硬误差球与现有闭环不相容；不能记录为通过 |
| `runtime_probe_contact25_still.json`，18 s 静止 trot | 未侧翻，283 次非空走廊，156 帧地图，最大 roll/pitch 0.0291/0.0320 rad | 一次短程静止执行可行 |
| `runtime_probe_contact25_forward.json`，25 s，forward=0.15 | 未侧翻，428 次非空走廊，227 帧地图，最大 roll/pitch 0.0199/0.0160 rad | 一次低速前进可行；没有跨到 x=2.25 的楼梯 |
| `runtime_probe_final.json`，降耗前的新启动，18 s，forward=0.15 | 侧翻；222 次非空走廊、167 帧地图 | 暴露额外实时负载问题，不能标记通过 |
| `runtime_probe_baseline.json`，关闭走廊，同输入18 s | 未侧翻；221帧地图，最大 roll/pitch 0.0276/0.0383 rad | 基线对照一次通过，支持检查新增负载 |
| `runtime_probe_optimized.json`，最终降耗版本，25 s，forward=0.15 | 未侧翻；421 次非空走廊、211 帧地图，最大 roll/pitch 0.0247/0.0272 rad，最终 x=0.404 m | 最终代码一次低速 smoke test 通过；未到达楼梯 |

phase=0.10 到 0.25 的复测还调整了测试脚本的控制命令脉冲和地图订阅路径，因此不能据这两组数据作严格单变量因果结论。降耗前的再次侧翻也说明不能仅以一次成功宣布稳定。后续关闭走廊对照通过，触发了有实测依据的等价降耗，最终复测通过；这些短程样本仍不足以给出成功率或误差管不变性结论。

降耗前在线规划日志：1386 次规划，1307 次完整走廊约束复核通过，79 次失败进入既有名义参考回退；成功复核的最大有限残差 -1.19617e-6 m。规划时间 P50/P95/P99=6.06/7.22/7.82 ms，最大 12.83 ms（含工作空间查询）。见 `data/runtime_metrics_74.json`。

最终降耗版本在线规划：2680 次规划、2111 次完整走廊复核通过、569 次回退；最大有限约束残差 6.94e-18 m（小于 1e-9 接受阈值及 1e-7 m 数值预算）。单足规划 P50/P95/P99=5.13/6.02/6.97 ms，最大 10.99 ms。关闭走廊对照 P50/P95=4.18/4.89 ms。见 `data/runtime_metrics_76.json`、`data/runtime_metrics_75.json` 和逐次记录 `data/runtime_planning_76.csv`。统计包括日志中的短剩余时域及工作空间查询，不能当作标准固定时域公平基准。

走廊复核成功说明参考几何满足约束，不能推导实际跟踪误差界已成立。最终短测保持直立，但回退比例约 21%，因此没有将其描述为每次摆动均获得认证，也没有替换原有失败策略。

## 现存失败与结论

既有 `swing_qp_regression` / `--continuity-only` 在 `Swing outside the MPC horizon triggered terrain optimization` 断言失败。断言统计的是 `heightQueries`，现有自适应摆高逻辑在时域判断之前已有地形采样。本次没有为通过旧断言重排冻结/时域行为。

既有 `minvo_test` 整包构建中，独立 `swing_cache_diagnostic` 目标缺少 `grid_map_core/eigen_plugins/FunctorsPlugin.hpp` 的 include 搜索路径。此次用指定目标构建并执行相关 MINVO/摆动回归，没有改动该无关目标。

**当前可以支持：** 在已知的静态高度地图及所配置的误差预算有效时，能构建严格避开保守膨胀障碍的分段三维凸多面体，并准确转换为 MINVO 控制点约束及双积分器 HOCBF 加速度约束。已接入实际感知地图与摆动 QP，成功输出经过完整走廊矩阵复核。

**当前不能支持：** 整段非接触摆动/接触切换的统一误差管保证、经过 WBC 的 HOCBF 执行保证、重复稳定行走或整段楼梯通过。已有名义回退没有走廊认证，未知地图及不可行约束仍会触发它；后续需要接续/更新准入与经过认证的备份策略，不能把回退成功发布当作安全认证。
