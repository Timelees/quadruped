# 地形安全走廊、MINVO 与闭环验证记录

更新：2026-11-18。2026-11-17 的短程 smoke test 原始结论保留于 [历史记录](VALIDATION_2026-11-17.md)；以下为当前配置的完整场景复测。原始失败记录保留，没有用最终成功轮次覆盖。

## 实现与本轮稳定性修正

复用生产五次 B-Spline、精确多项式提取/细分、MINVO、qpOASES、GridMap 与 ROS Marker。保持固定 XY / Z QP 架构，完整三维矩阵供约束导出及接受前复核；未引入求解器或几何依赖。

| 问题 | 证据与修正 |
|---|---|
| 计划支撑但足端悬空 | `stairs_repeat_89` 的 RF 在 ROS t=27.676 s 切入支撑，估计足端中心 z=0.24346 m，真实第二级踏面+足半径为 0.219 m，sensor RF=1.56 N。后续约 0.35 s 支撑窗口的中位 gap=32.74 mm、力=0.68 N；最终 `stairs_final_104` 对应事件的中位 gap=−0.19 mm、力=28.50 N。这是缺少有效支撑的实测诊断，不能仅凭它归因于冲击峰值。 |
| 深度相机/高程偏差 | 删除 Gazebo 相机与 FOV/图像尺寸不一致的手写 intrinsics/distortion，并将仿真地图 36.5 mm 经验补偿清零。`stairs_map_91` 与 `stairs_camera_96` 在 ROS 5–12 s 的共同踏面（0.1/0.2/0.3 m）中位地图误差由 9.49/16.21/27.35 mm 变为 −0.90/0.002/0.008 mm。两轮位置/可见范围不同；地图帧不是独立实验重复。实机标定未修改。 |
| 地形俯仰未持续生效 | 原条件检查每个插值参考的 pitch 是否恰为零，实测倾斜会使地形对齐被跳过。改查操作端终端 pitch，并从测量初始 pitch 在 0.3 s 内混合到地形目标；目标限幅 ±0.20 rad。未限幅版本平台通过，但楼梯失败，因此最终统一使用限幅配置。 |
| MPC 足端 Z 参考执行不够强 | 地形路径启用可配置硬 Z 跟踪等式，增益 20；保留软 XYZ 代价及 XY 增益 1.5。普通路径关闭时不注册；生产控制问题回归验证注册、值、Jacobian 和 clone。 |
| WBC 无效解未检查 | 检查 qpOASES 返回值、有限性和约束残差，冷启动工作集预算 20→100。无效解退出 passive；新增按订阅和时间间隔发布的诊断。 |
| 走廊顶面宽松 | 单段参考凸包外的上下扩展 0.25→0.08 m，规划集继续收缩 0.02 m。下方障碍分离平面保持保守。收紧后的默认值通过几何与生产 QP 测试。 |
| 时域外重复查询 | 自适应摆高扫描仅对与 MPC 时域相交的摆动执行；扫描最大高程初始化为负无穷，兼容负高程。原 horizon/continuity 回归失败已解决。 |

相机、地形姿态、跟踪和步态参数共同构成最终配置。上述旧/新运行是诊断对比，未将其标作单变量消融。

MINVO 合成基准为 27 个几何：3 高度×3 宽度×3 障碍中心；每种方法计时重复 5 次，共 405 行。结果分类只计 repeat=0 的 27 个独立输入。

| 方法 | 求解且独立认证 | 求解但发生碰撞 | 未求解 |
|---|---:|---:|---:|
| 离散配点 | 16 | 6 | 5 |
| Bézier 连续凸包 | 18 | 0 | 9 |
| MINVO 连续凸包 | 18 | 0 | 9 |

这组基准支持连续凸包约束能排除离散配点漏检的碰撞，**没有显示 MINVO 相对 Bézier 的通过数量优势**。同一解析曲线族的投影下界间隙为 Bézier 50 mm、MINVO 29.1906 mm，缩小 20.8094 mm（41.62%）；这是特定曲线族的配对几何结果，不是任意曲线的统一改善比例。

## 数据、图表与复现

- `run_trial.py`：独立仿真、配置快照、源码 SHA256、仅清理自有进程组。
- `scenario_probe.py`：真实目的面判定、转向符号、真值/估计/力/地图/参考采集。
- `analyze_stability.py`：全部结果与最终六轮单列，输出 `trial_metrics.csv`、`contact_events.csv`、`stability_summary.json`。
- `plot_evidence.py`：从生产导出/基准/运行 CSV 生成五组图，PDF、SVG、600 dpi PNG；图注与 QA 见 [figures/README.md](figures/README.md)。
- 完整命令见工作区根目录 `QUICK_START.md` 及本包 [README](README.md)。

历史失败不进入最终同配置六轮分母，但保留在 `trial_metrics.csv` 和原始目录。`stairs_repeat_89` 是旧相机失败；`stairs_map_91` 是标定前失败；`stairs_camera_96` 因旧驱动终点减速超时，未算成功；`platform_*98/99` 是修正相机后尚未修正姿态的失败；`stairs_pitch_101` 是未限幅地形 pitch 失败。`probe_error` 属采集异常，和算法失败分开记录。缺少完整 JSON 的中断运行不计为完成试验。以每条 JSON 的实际 result 为准，不从日志末尾的 Gazebo 清理堆栈推断跌倒。

## 认证对象

本实现已证明并验证的对象是**已知静态高度地图下的分段三维几何集合、规划收缩集合以及 MINVO/HOCBF 代数转换**。在线已接入实际地形与摆动优化，六轮闭环路线通过。

在线常量 2 cm 跟踪球仅覆盖 `[0.25,0.75]`，接触过渡段不在该证书内；独立几何测试为 `[0.10,0.90]`。回退名义轨迹未认证。HOCBF 仅导出，未接入 WBC。`verifySwingOutput=false` 不提供接触过渡段的独立认证。工作空间边界扩展、实际误差管、单元切换执行可行性、全身碰撞及动力学都没有由单足几何结果自动证明。当前硬导数行仅约束修正速度，配置中的加速度数值不是已落实的硬界。
