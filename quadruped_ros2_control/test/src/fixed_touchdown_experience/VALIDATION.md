# 固定触地摆动优化：实现与实验证据核验

本轮结果：**算法层的固定终端时刻、p/v/a 边界及非接触 MINVO 几何约束已取得可复现证据；指定 Gazebo 场景中“旧轨迹碰撞→同次摆动真实激活→避障成功”的整机链路尚未验收。** 六张图中，1/3/4/5 为明确标识的生产算法离线试验，2/6 为最终版本 Gazebo 实测。没有用路线通过、单腿准入、后续摆动或人工曲线替代真实换轨。

## 1. 本轮代码修改与验收状态

沿用既有 MPC→MRT→WeightedWbc 架构、样条工具、走廊构建器、测试驱动及诊断格式，没有新建控制架构或引入规划依赖。

## 2. 算法机制试验

最终输入/输出：[mechanism_release](data/mechanism_release/)，完整参数见 README。112个确定性全因子条件中，13个通过实际边界实例化，13个均将旧轨迹碰撞修复为正净空；99个拒绝。10/11 cm存在接受条件，12/13 cm该扫描未取得接受解。**13/112是指定条件的计数，不是机器人成功概率；拒绝也不表示全局不存在可行轨迹。**

独立 NumPy 重算与原生 C++ trace 的 p/v/a 最大差约1.42×10⁻¹⁴。全部接受样条的终端三维残差最大值：位置4.44×10⁻¹⁶ m、速度3.47×10⁻¹⁸ m/s、加速度4.58×10⁻¹³ m/s²。独立读出66个 MINVO 单元的映射和规划平面，最大约束违反量1.46×10⁻¹⁷ m，处于数值容差内。密集距离扫描仅作辅助复核；连续约束证据来自生产 MINVO 行，而不是“采样够密”。

图1/3/4/5的预定选例规则：先选择真实碰撞修复激活；没有时在离线接受例中按最大注入延迟、再按最晚显露、再按最低障碍选取。最终选例为10 cm、触发0.020 s、实例化0.035 s、固定 `t_f=0.400 s`：旧参考最小球体净空−25.158 mm，新参考+49.605 mm。稀疏相位 .25/.50/.75 的旧轨迹检查均未检出碰撞。实际边界匹配残差约 `[1.1e-16,6.3e-15,2.1e-14]`。

该离线例提供受控旧参考 p/v/a 作为边界；它验证生产构造和约束，并不证明机器人状态、感知或控制输入满足相同条件。机制配置 .16 s 修正时长与机器人默认 .12 s 不同，未混称为同配置物理结果。

06目标摆动：首次观测到非接触模式22.130 s，观测触发22.200 s，控制器提交新地图22.265 s；由规划日志的激活时刻+剩余时间复原，固定终端为22.500 s。剩余0.235 s时固定状态约束拒绝；后续0.135 s时状态偏差超门限。07首次观测非接触模式27.710 s，控制器新地图27.775 s，规划日志固定终端28.095 s；候选在0.320 s剩余时间被固定状态约束拒绝，关闭HOCBF仍没有真实激活。采样中首次观测离地可能晚于计划模式切换，因此不以“该采样时间+.4”冒充精确计划终端。时间用同一控制器时钟比较，不将ROS绝对时钟与控制器相对时钟相减。

08出现最终换包拒绝：验算34.14 ms超过5 ms周期、候选加速度包络87.24 m/s²超过80限值、联合WBC不可行、终端不一致。保留这些拒绝及原始日志，没有提高导数、状态偏差或时间上限制造成功。部分 `terminal_changed` 还可能包含缺少同次摆动旧引用的身份不匹配；现有日志无法直接解释为物理终端改变。

平均动力学残差下界诊断仅在有有效活动安全行的区间记录：最终06为42个样本超过0.5 m/s²，最大30.83；08为296个、最大24.08。有限差分与速度测量预算相关，它们不是瞬时真值加速度；在诊断所假设的速度误差界成立时可以反证0.5预算，不能反过来以未超界证明确定性上界。07关闭过滤时该诊断未启用，无样本不代表满足预算。源数据见 [run_audit.json](data/analysis/run_audit.json)。

## 5. 与初稿论点的对应及下一步清单

**已有证据：** 初稿2.3固定剩余时长问题中的参考初末边界；3节对指定走廊的连续几何行；4.4五次Hermite修正及终端保持的构造性案例。全部为明确条件下的算法证据，不等同于完整递归可行或实际执行定理。

**优先级P0：补足用户要求的整机正例。**

1. 在同一10 cm世界捕获产生 `candidate fixed-state constraint violated` 的完整初值、行号、上下界和固定控制点贡献；区分初始p/v/a已越导数/工作空间界、固定XY与走廊不相容、数值消元及单一修正时长过保守。没有可靠不可行证书时，只写“拒绝”。
2. 实现初稿所写的修正时长有限枚举和候选失败后的独立剩余QP。当前仍单一修正时长，固定XY只优化Z；不要将离线能修复直接推成真实初值也能修复。
3. 把新旧参考身份、原定终端边界与地图版本绑定到完整摆动，细分 `terminal_changed`，避免一个非目标腿的身份/终端问题阻断整包又无可诊断信息。
4. 将几何/导数族证书移至可预算的预验算阶段，实际tick仅选实例和验证证书适用域；当前20–34 ms级最后验算不能塞进5 ms tick。需要证明验算用时覆盖的状态变化，不可简单放宽时间门。
5. 在同一目标摆动记录 `SWING_EVIDENCE`、实际WBC使用、新旧参考安全、真实足端跨障与原tf终端，完成成功正例后再做独立重复。最终版本普通行走回归也须通过。

**优先级P1：从参考构造提升到论文严格约束。**

6. 为整段构型和关节限位建立有效工作空间内近似，或将论文明确限定为采样IK启发式筛查；实际激活修正族也必须包含工作空间验证。
7. 用时间对齐的真实速度/加速度、电机输入与接触状态标定分配输入偏差，给出0.5 m/s²等预算适用域；覆盖跟踪干预与饱和。当前数据反而提示预算不可信。
8. 完成踏面边缘、邻近同高面、目标无穿透的完整模式/几何回归，并单独验证真实合法触地事件。参考终端与实际触地不能混为一谈。
9. 初稿式20的目标函数、XYZ优化范围、修正时长择优及数值认证材料与实际实现逐项对齐。本文未新增“可变触地”算法。

剩余持续执行流、不变误差管及HOCBF联合理论保证按用户本轮范围不作验收。即便暂不评价HOCBF，也不能用参考几何替代实际安全。
