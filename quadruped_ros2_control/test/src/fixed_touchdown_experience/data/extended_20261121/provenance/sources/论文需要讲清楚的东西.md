# 核心观点论证

## 核心矛盾

四足机器人在复杂地形中运动时，摆动足需要根据新获取的环境信息实时调整轨迹，但摆动相的结束时间往往已经由上层步态规划和全身运动协调确定。==局部避障调整如果随意改变触地时刻，可能破坏原有接触时序及全身协调；如果保持原定触地时刻，则随着剩余摆动时间缩短，轨迹调整将受到越来越严格的动力学与安全约束。==因此，**如何在不改变既定接触时序的情况下，实现摆动足轨迹的安全、连续且可执行的在线更新，是一个具有实际意义的研究问题。**



区分两个概念：

- **固定触地期限（Fixed Touchdown Deadline）**：要求摆动足在给定的时间约束下完成运动。
- **固定触地时刻（Fixed Touchdown Time）**：要求轨迹在预定的绝对时刻满足终端状态，并实现与接触模式的协调。



**环境适应性与接触时序一致性**

上层步态协调器已经确定触地时刻：

$t_f=\mathrm{const}. $

摆动足只能通过改变空间轨迹适应新环境。

因此，随着时间推进，存在三个相互竞争的要求：

**第一，空间安全要求。**

$p_d(t)\in\mathcal C_{\mathrm{safe}}(t) $

足端必须避开障碍物。

**第二，时间约束。**

$p_d(t_f)=p_{\mathrm{target}} $

必须在预定时刻到达目标位置。

**第三，运动可执行性。**

$\begin{aligned} \|\dot p_d(t)\|&\le v_{\max},\\ \|\ddot p_d(t)\|&\le a_{\max},\\ u_f(t)&\in\mathcal U_{\mathrm{real}}(x). \end{aligned} $

调整轨迹不能超过机器人的实际执行能力。

于是，你的研究问题可以概括为：

$ \boxed{ \text{空间避障} + \text{固定触地时刻} + \text{运动可执行性} } $

三者必须同时成立。

**这三个条件的相互制约，就是论文最值得深入研究的矛盾。**





## 固定触地时刻下的摆动相轨迹优化的优势

**在接触时序需要保持稳定、但摆动轨迹又必须实时调整的情况下，提高机器人局部环境适应能力，同时减少轨迹调整对上层步态与全身协调的干扰。**



### **场景**1：机器人连续行走时，突然发现原摆动轨迹存在碰撞风险

若重新规划，同时延长摆动时间，足端能够获得更多时间绕过障碍物。但是其他腿的接触时序可能按照原来的步态执行。==延迟触地可能改变原先安排的支撑状态==，特别是在机器人高速行走、支撑裕量较小或全身控制对接触切换时刻较为敏感时，这种变化可能增加姿态稳定和控制协调的难度。

当然，能够联合重新规划接触时序和全身运动的控制器可以处理这种变化，因此不能笼统地说延长摆动时间一定导致失稳。



**价值：**

**实现不改变接触时序的摆动内避障。**

更具体地说，它能够：

① 提高机器人对摆动期间新发现障碍物的适应能力。

② 在可行条件下维持原定步态相位和触地安排。

③ 避免每次局部轨迹调整都必须触发全身接触时序重规划。

④ 在剩余时间不足时识别不可执行的调整，避免强行跟踪。



**必须分别证明**：

- 相比不更新，在线优化确实能够处理新的障碍风险；
- 相比允许延迟触地，固定时刻方案在可行任务中具有更小的接触时序偏差；
- 当障碍过大或出现过晚时，允许延迟触地可能更容易找到可行解。

承认最后一点，反而会让论文更可信。



### 场景2：机器人高速运动时，避免局部轨迹调整破坏步态节奏

在高速 Trot、Running Trot 或 Bounding 等运动中：机器人各条腿的摆动和支撑切换通常与机身运动、质心状态以及接触力分配密切耦合。

上层控制器已经基于接触计划生成对应的质心轨迹和接触力参考。

如果局部足端优化器为了绕开障碍，将触地时刻延长，其他腿的运动计划不进行调整时，可能出现：

- 实际支撑腿数量与预测不一致；
- 原规划接触力无法按时施加；
- 质心轨迹与接触状态不匹配；
- 机身姿态误差增大；
- 步态切换过程出现较明显扰动。





**算法价值：**

**允许足端空间运动轨迹变化，但不允许这次局部更新擅自改变接触事件的预定时间。**

这是一种空间轨迹适应与时间调度保持相分离的设计。

它的价值不在于固定时间本身提高了稳定性，而在于：

> 当全身运动控制器依赖既定接触时序时，局部轨迹更新能够保持与该时序的一致性，减少局部变化向全身运动计划传播的影响。



可以关注的指标

| 评价指标             | 研究意义                 |
| -------------------- | ------------------------ |
| 触地时间误差         | 验证接触时序保持能力     |
| 机身 Roll/Pitch 峰值 | 检查姿态受到的影响       |
| 质心轨迹跟踪误差     | 评估全身运动协调         |
| 支撑接触力变化       | 评估接触切换影响         |
| 摆动足最小净空       | 确认避障安全性           |
| 单步调整成功率       | 验证实时适应能力         |
| 平均运动速度         | 检查避障是否影响行进效率 |



### 场景3：机器人跨越台阶、连续障碍时，维持稳定的落脚节奏

考虑机器人需要连续通过：

- 不规则台阶；
- 高低交替的石块；
- 多个连续凸起；
- 狭窄但可通行的落脚区域。

在这些地形中，机器人不仅需要足端避障，还需要保持预先规划的接触顺序。



上层已经规划了：

- 摆动起始位置；
- 目标落脚区域；
- 触地时刻；
- 支撑腿接触状态。

但在摆动期间，新的地图信息发现台阶边缘比原先预测的位置更靠近足端路径。

这时机器人需要临时增加抬腿高度或改变摆动路径。

如果仅仅增加抬腿高度，而不考虑剩余摆动时间，就可能要求过大的足端速度或加速度。



**价值：**

**体现的不是固定触地时刻让机器人跨得更高，而是让机器人能够明确知道：在不改变既定接触时序的情况下，还能安全完成多大程度的轨迹调整。**

在保持终端时间的情况下，联合判断：

$ \text{安全避障} + \text{运动学与输入限制} + \text{准时到达} $

是否仍然可以同时满足。



可以引出你论文中一个值得重点强调的概念：

**固定时间下的安全轨迹调整能力**

例如，定义：

$\mathcal A_{\mathrm{safe}}(T) $

表示在剩余时间 \(T\) 内，满足安全、运动和终端条件的可行轨迹调整集合。

随着剩余摆动时间缩短：

$T\downarrow $

通常会出现：

$\mathcal A_{\mathrm{safe}}(T) $

逐渐受限的现象。

但需要注意，不能直接断言不同剩余时刻的可行集合严格单调嵌套，因为初始状态、地图以及终端条件可能同时变化。

你可以通过固定可比较条件的实验来研究其变化规律。

这将使论文从“提出一个轨迹优化算法”上升到：

**研究固定接触时序约束下，摆动足对环境变化的安全适应能力及其边界。**



### 场景4：机器人接收到延迟的地形感知信息，仍需安全完成当前摆动

这一场景与论文目前第 4.4 节的数学内容非常契合。

机器人使用视觉、高程地图或其他传感器感知地形时，新信息并不总能在摆动开始前获得。

可能存在：

$t_{\mathrm{obs}}<t_k<t_k^a<t_f $

其中：

- $t_{\mathrm{obs}}$：地形观测时刻；
- $t_k$：开始规划时刻；
- $t_k^a$：新轨迹实际激活时刻；
- $t_f$：原定触地时刻。

由于感知、优化和通信都需要时间，机器人真正开始执行新轨迹时，剩余摆动时间已经减少。

你的初稿已经明确考虑：

$T_k=t_f-t_k^a $

而不是简单地采用规划开始时刻计算剩余时间。

能避免一种常见的问题：

**优化器生成了一条在规划开始时看起来可行的轨迹，但在实际激活时已经没有足够时间执行。**



**价值：**

说明你的研究不仅关注“能否计算出一条轨迹”，还关注：

> **在线优化得到的轨迹，在真正交给机器人执行的那个时刻，是否仍然安全、连续且能够按时完成。**



## 论文核心要讲清楚的东西

将论文的核心从：

**固定触地时刻下的安全轨迹优化**

进一步凝练成：

**接触时序约束下，四足机器人摆动足在线避障的安全性与可行性问题。**





### ==1.定义固定期限下的可行更新集合==

给定激活时刻 $t_k^a$、当前状态 $x_k$、地图 $\mathcal M_k$、目标触地时刻 $t_f$，定义：

$ \mathcal F_k= \left\{ q: \begin{array}{l} A_{\mathrm{eq},k}q=b_{\mathrm{eq},k},\\ A_{\mathrm{pos},k}q\le b_{\mathrm{pos},k},\\ A_{\mathrm{der},k}q\le b_{\mathrm{der},k},\\ A_{\mathrm{ws},k}q\le b_{\mathrm{ws},k},\\ A_{\mathrm L,k}q\le b_{\mathrm L,k} \end{array} \right\}. $

这个集合与初稿第 3.4 节建立的二次规划直接对应。

当：

$\mathcal F_k\neq\varnothing $

说明在当前规划模型下存在满足约束的参考轨迹。

但这还不是完整的实际执行保证。

还需要满足第 4 节中的跟踪误差、安全屏障及可执行输入条件。

因此，可以进一步定义：

$ \mathcal F_k^{\mathrm{exec}} = \left\{ q\in\mathcal F_k: \begin{array}{l} \text{激活状态满足安全初值条件},\\ \text{后续存在满足联合约束的控制输入} \end{array} \right\}. $

这里使用“执行可行轨迹集合”的概念，并明确：你当前的在线准入检查提供的是有条件的可行性判定，不能仅凭某一瞬间 QP 可行，就认定整个剩余摆动阶段始终可行。

### ==3.什么时候来得及调整---建立“剩余时间—障碍调整幅度”关系==

腿部完成大部分摆动运动时，突然有一个障碍物在该腿的剩余摆动区间内出现，是否能够来得及调整轨迹，避障。

对于具有实际动力学、碰撞、速度和 jerk 约束的四足机器人。这意味着：==固定触地时刻下，摆动足的避障调整能力存在明确的时间限制。==

**回答**：当机器人在摆动过程中获得新的地形信息时，如何确定剩余时间内是否还存在安全、连续且可执行的轨迹？如果存在，如何在线求解；如果不存在，如何避免激活不安全的轨迹？



假设机器人在摆动期间发现新障碍，需要调整的最小空间幅度为：

$d_{\mathrm{req}}. $

可以通过仿真实验研究：

$f(T,d_{\mathrm{req}}) $

其中：

- $T$：实际激活时刻到触地时刻的剩余时间；
- $d_{\mathrm{req}}$：避障所需的调整幅度；
- $f$：在线更新成功率或可行性判定结果。

建议使用二维热力图：

横轴为剩余摆动时间，纵轴为障碍调整幅度，颜色为成功率。

进一步绘制：

$d_{\max}(T) $

表示在一组明确规定的障碍参数化场景中，给定剩余时间内能够通过认证的最大调整幅度。

注意，这里的 $d_{\max}(T)$ 是在指定场景族和认证规则下定义的，不应直接解释为机器人的全局最大避障能力。





### ==4.固定触地时刻下的连续时间安全轨迹构造==

**在时间不能延长的条件下，尽可能利用剩余的轨迹调整自由度，同时避免离散碰撞检查遗漏采样点之间的碰撞。**



==验证==：

在相同安全走廊、相同时间预算和相同决策自由度下，MINVO 相比 Bernstein 或其他约束方式，究竟能降低多少保守性、提高多少可行率。



### ==5.固定终端时间下的状态接续与更新准入==

**如何避免在线优化过程中出现“轨迹已计算完成，但在实际激活时不再安全或无法按时完成”的情况？**

**最应该重点突出的贡献**。

一般的在线重规划问题，需要考虑：

$p_{\mathrm{new}}(t_k^a) = p_{\mathrm{current}}(t_k^a) $

以及速度、加速度连续。

但你还要求：

$p_{\mathrm{new}}(t_f) = p_{\mathrm{target}} $

并且：

$t_f=\mathrm{const}. $

论文第 4.4 节通过五次 Hermite 修正构造：

$p_c(t)=p_o(t)+d(t) $

使更新轨迹能够在当前激活状态与原定终端条件之间接续。

更关键的是，不仅进行了状态接续，还检查轨迹修正是否消耗了过多安全裕量，以及新的规划约束是否仍然可行。

这部分真正解决的问题是：

> **如何避免在线优化过程中出现“轨迹已计算完成，但在实际激活时不再安全或无法按时完成”的情况？**

这比单独提出一个状态插值函数更有价值。

不过，目前第 4.4 节给出的定理是**条件递归可行性**，并没有证明任意环境变化后都能保持可行。论文需要继续保留这一限定。







5.==固定接触时序下的规划—执行安全一致性==

规划层通过 MINVO 和安全走廊保证参考轨迹的几何安全。

执行层通过：

$\text{Tracking Tube} + \text{HOCBF} + \text{Realizable Inputs} $

将实际足端运动限制在允许的安全范围内。

解决了：

**参考轨迹满足安全约束，并不意味着实际机器人一定能够安全执行的问题。**

这一设计尤其适用于摆动末期。

因为此时剩余时间很短，即使规划器仍然能够计算出一条无碰撞轨迹，实际关节和执行器也未必能够在有限时间内跟踪它。

这里需要强调的是，误差管、HOCBF 和真实输入集合之间的共同可行性，而不是简单地把三个模块叠加在一起。



## 创新点

### 1.安全更新的可行性边界

建立一个核心问题：

> 给定当前足端状态、剩余摆动时间和地形变化，机器人是否还能够在原定触地时刻前完成安全轨迹调整？

这个问题同时涉及：

$\text{Reachability} + \text{Safety} + \text{Deadline}. $

这里还可以进一步考虑一个量：

$ T_{\min}(x_k,\mathcal M_k,p_f), $

表示在明确规定的约束与轨迹类别下，从给定状态安全完成目标运动所需的最短可行时间。

然后比较：

$T_k\ge T_{\min} $

是否成立。

但要注意，在复杂非凸障碍、真实动力学以及保守安全走廊条件下，精确求解全局最短可行时间可能非常困难。

一个实际可行的研究方向，是构造保守但可计算的可行性判据，而不是追求全局精确最短时间。



### 2.用固定时间约束解释轨迹更新的必要性

通过实验回答：

为什么在步态时序固定时，不能随意采用普通的轨迹重规划？

比较：

- 不考虑剩余时间的重新生成；
- 固定终端时间的直接重新生成；
- 加入状态接续的重新生成；
- 加入完整安全认证与准入的重新生成。

观察：

$ \text{连续性误差} ,\quad \text{可行率} ,\quad \text{实际碰撞率} ,\quad \text{触地时间偏差}. $

如果这些差异显著，就能够证明你的状态接续与准入机制确实解决了实际问题。



### 3.将安全性从参考轨迹传递到实际足端

已有方法可能生成一条无碰撞参考轨迹，但实际执行时仍然存在碰撞风险。

你的研究可以展示：

$\text{Reference Safety} \not\Rightarrow \text{Execution Safety}. $

然后说明，在满足特定模型和控制可行性条件时：

$ \text{Continuous-Time Certification} + \text{Robust Tracking Contract} \Rightarrow \text{Execution Safety}. $

这能够将你提出的 MINVO 和 HOCBF 从两个独立工具连接为一个有理论依据的框架。



## 论文核心故事组织

#### 第一阶段：先建立现实问题——局部轨迹调整与全身接触时序之间的矛盾

首先说明：

四足机器人在复杂地形中依靠预先规划的接触时序协调机身与足端运动。

由于局部地形感知存在不确定性和处理延迟，机器人可能在摆动已经开始后才发现新的碰撞风险。

此时，需要对正在执行的足端轨迹进行更新。

然而，如果局部轨迹优化任意调整摆动持续时间，可能使原定的支撑状态与实际接触状态产生偏差。

如果保持既定触地时刻，更新算法又必须在不断缩短的剩余时间内同时完成避障、轨迹接续与可执行性约束。

因此产生核心问题：

$ \boxed{ \begin{gathered} \text{已确定接触时序}\\ \Downarrow\\ \text{摆动期间感知或状态变化}\\ \Downarrow\\ \text{需要在线修改足端轨迹}\\ \Downarrow\\ \text{剩余时间受限，安全与执行约束耦合} \end{gathered} } $

这就是论文的研究动机。

#### 第二阶段：明确现有方法的不足

围绕三个具体不足展开：

**不足 A：离散轨迹约束不能直接提供整段时间的碰撞安全保证。**

需要注意，已有研究也存在连续时间碰撞约束方法，因此要明确比较对象，而不是宣称所有现有方法只能离散检查。

**不足 B：轨迹重规划与实际激活之间存在时间和状态偏差。**

重新计算轨迹并不代表它在实际切换时仍然满足初始边界与终端要求。

**不足 C：参考轨迹的几何可行性无法直接保证实际足端的安全执行。**

特别是在剩余时间较短时，输入饱和、跟踪误差和安全过滤可能使规划结果难以执行。



#### 第三阶段：提出统一解决方案

建议论文的方法框架突出以下链路：

$\boxed{ \begin{aligned} &\text{固定接触时序}\\ &\downarrow\\ &\text{剩余时间内的连续时间安全规划}\\ &\downarrow\\ &\text{实际激活状态接续与可行性准入}\\ &\downarrow\\ &\text{具有执行约束的安全跟踪}\\ &\downarrow\\ &\text{目标接近与安全触地} \end{aligned} } $

这样 MINVO、Hermite 和 HOCBF 就不再是三个相对独立的技术模块，而是共同服务于一个明确的任务：

**在不改变原定接触事件时间的前提下，安全地接受并执行摆动内轨迹更新。**





## 实验指标关注

==把“安全可更新边界”作为论文的重要研究结果==

围绕以下问题组织实验：

**在固定触地时刻下，机器人还剩多少时间、面对多大的轨迹调整需求时，才能安全完成在线更新？**



### 1.固定触地与可变触地策略的比较

#### 设置四组核心方法

| 方法                      | 在线避障 | 触地时间 | 执行安全               |
| ------------------------- | -------- | -------- | ---------------------- |
| A：固定名义轨迹           | 不更新   | 固定     | 常规跟踪               |
| B：可变触地时间重规划     | 更新     | 允许调整 | 相同的安全控制配置     |
| C：固定触地时间直接重规划 | 更新     | 固定     | 缺少状态接续与准入机制 |
| D：本文完整方法           | 更新     | 固定     | 连续时间认证与安全执行 |

为了公平，建议 B、C、D 尽量使用相同的轨迹参数化、地图、目标函数、计算预算与控制器。

对于 B，还应明确它是否允许同步修改全身接触计划：

- 如果不允许，那么比较的是局部时间调整对原接触计划的干扰；
- 如果允许，那么比较的是不同规划架构，必须计入全身重新规划的计算成本和效果。

这两种比较不能混为一谈。

#### 实验一：中途发现障碍

在摆动的不同阶段注入障碍信息：

$25\%,\quad 50\%,\quad 75\% $

比较各方法是否能够安全完成当前摆动。

重点研究：

**在线更新是否能够扩大机器人处理迟到地形信息的能力。**



#### 实验二：步态时序保持能力

在相同障碍条件下，记录：

$e_t=t_{\mathrm{contact}}-t_f $

其中 $t_{\mathrm{contact}}$ 是实际检测到的触地时间。

同时记录：

$e_{\mathrm{phase}} $

即实际接触事件与原计划步态相位之间的偏差。

这两个指标可以直接体现固定触地时刻的工程意义。

但有一个你必须注意的问题：

**你的方法能够强制参考轨迹在 \(t_f\) 满足终端边界，并不自动证明实际足端一定在 \(t_f\) 发生物理接触。**

实际触地还受到地面高度误差、跟踪误差、末端速度和接触检测的影响。

你目前第 4.3 节已经讨论接触模式切换，这是正确方向。

如果论文最终声称“准时触地”，必须在实验中测量真实接触时间，并且最好给出终端法向误差、允许触地速度和接触时间容差。

否则，理论主张应当表述为“保持预定触地边界和接触时序计划”，而不是无条件保证实际接触严格发生在指定时刻。



#### 实验三：剩余时间与调整幅度

这是最能展示方法独特性的实验。

研究：

$P_{\mathrm{success}}(T,d) $

并绘制安全更新成功率热力图。

此外，建议统计：

- 认证可行率；
- 实际执行成功率；
- 新轨迹被拒绝的比例；
- 因几何约束拒绝的比例；
- 因导数约束拒绝的比例；
- 因控制输入不可行拒绝的比例；
- 因计算或激活超时拒绝的比例。

这样，你可以得到一个很有价值的结论：

**在线更新的失败究竟是由剩余时间不足、空间障碍过强，还是控制执行能力不足导致的。**

这会直接支持你提出的更新准入机制。



#### 实验四：全身运动性能



使用完整trot步态让机器人连续通过带有突起的地形。

在摆动期间触发轨迹更新，然后比较：

$ \mathrm{RMS}(e_{\mathrm{CoM}}) $

机身姿态峰值，以及接触时序误差。

这个实验的意义在于验证：

**保持既定触地时刻是否能够减少局部足端调整对全身运动协调的影响。**

如果结果成立，这将成为论文中非常有力的应用价值证据。

如果结果并不显著，也不意味着你的方法没有意义；可以将主张收敛到固定接触时序条件下的局部安全更新和可行性认证。

### ==**图：MINVO 与 Bernstein 的凸包几何对比**==

![image-20261120114748109](https://gitee.com/Leesj008/typora-image/raw/master/images/image-20261120114748109.png)

论文采用五次 B-Spline 表示轨迹，通过 MINVO 基变换构造包络。

如果采用传统 Bernstein 基，轨迹可以写为：

$ p(s)=\sum_{j=0}^{5}B_j^5(s)b_j $

而 MINVO 表示为：

$ p(s)=\sum_{j=0}^{5}\phi_j(s)v_j. $

两者描述的应当是**完全相同的多项式曲线**。

不同的是，它们所构造的凸包可能不同。

因此，建议图中同时展示：

- 黑色实线：同一条五次多项式轨迹。
- 橙色多边形：Bernstein 控制点凸包。
- 蓝色多边形：MINVO 控制点凸包。
- 红色虚线：安全走廊约束边界。

理想的实验结果是，在部分狭窄走廊场景下，Bernstein 控制点无法全部满足约束，而 MINVO 控制点可以满足。

**正式实验推荐计算哪些指标？**

对于二维投影：

$A_{\mathrm{Bernstein}}\\A_{\mathrm{MINVO}} $

并计算：

$\eta_A= \frac{A_{\mathrm{Bernstein}}-A_{\mathrm{MINVO}}} {A_{\mathrm{Bernstein}}}\times100\%. $

对于三维足端轨迹，则应使用凸包体积：

$ V_{\mathrm{Bernstein}},\qquad V_{\mathrm{MINVO}}. $

此外，我更建议你增加一个直接与安全约束相关的指标。

对于某一条走廊边界：

$ a_r^Tp\le b_r, $

定义包络控制点的最小约束余量：

$ m_r=b_r-\max_j a_r^Tv_j. $

分别计算 Bernstein 与 MINVO 表示下的余量。

因为**凸包面积更小，不一定意味着在每一条安全半空间约束上都具有更大的裕量**。

**建议最终采用三联图**

(a) 相同五次轨迹的 Bernstein/MINVO 凸包。

(b) 不同走廊宽度下的规划可行率。

(c) 不同走廊宽度下的安全约束余量。

这比只展示两个凸包的面积，更能体现 MINVO 对在线安全轨迹规划的实际作用。

$ r_u(t)\le0 $

**(b) 辅助安全函数 \($\psi_{r,1}(t)$\)**

定义：

$ \psi_{r,1}(t) = \dot h_r(t)+\alpha_{r,1}h_r(t). $

对于你采用的二阶 HOCBF，其扩展安全状态条件包括：

$ h_r(t)\ge0 $

和：

$ \psi_{r,1}(t)\ge0. $

因此，不能只画 \($h_r(t)$\)。

还应该检查 \($\psi_{r,1}(t)$\) 是否满足对应条件。

**(c) 鲁棒 HOCBF 不等式残差**

根据你的动力学模型：

$\ddot p_f=u_f+w_f, $

对应的鲁棒约束为：

$ \begin{aligned} R_r(x,u_f)= &-a_r^Tu_f -\sigma_{\mathcal W}(a_r)\\ &+(\alpha_{r,1}+\alpha_{r,2})\dot h_r\\ &+\alpha_{r,1}\alpha_{r,2}h_r \ge0. \end{aligned} $

建议直接绘制：

$ R_r(x(t),u_f(t)). $

这样能够分别证明三个问题：

| 曲线                | 验证内容                          |
| ------------------- | --------------------------------- |
| \($h_r(t)$\)        | 实际状态是否位于安全区域          |
| \($\psi_{r,1}(t)$\) | 是否满足扩展安全状态条件          |
| \($R_r(x,u_f)$\)    | 控制输入是否满足鲁棒 HOCBF 不等式 |

参考图使用解析构造的简单安全函数，展示三种量均为非负的情况；第三幅图尚未加入非零扰动上界的鲁棒惩罚。

正式实验应该从控制器日志中计算完整的鲁棒残差。
