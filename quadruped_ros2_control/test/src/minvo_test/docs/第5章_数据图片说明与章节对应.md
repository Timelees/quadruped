# 第5章：数据、图片含义与章节对应

本说明对应 `minvo_test/data/` 和 `minvo_test/result/` 的当前结果。所有长度单位默认 m，时间单位 s；面积比较使用 XZ 投影面积。结果来自合成静态高程地图与控制器生产代码中的五次 B 样条、凸包变换、QP 和碰撞认证器，**不是 Gazebo 机器人行走日志、点云融合结果或实机实验**。

建议将本文件作为论文素材说明；正文只放关键图、指标和必要限制。复现输入以每个数据目录中的 `config.yaml` 快照为准，避免修改配置后误用旧图片。重新运行会覆盖同名结果。

## 2. 当前场景与轨迹方法

### 表1：场景输入

| 场景 | 地形 | 起落点 x 序列 | 说明 |
|---|---|---|---|
| single | 高0.06，x∈[0.145,0.175]，沿前进方向宽0.03 | 0.116 → 0.330 | 地面到地面；障碍靠近离地端，参考与障碍发生球体相交 |
| pillars | 四柱均高0.06，x范围[0.13,0.23]、[0.31,0.41]、[0.49,0.59]、[0.67,0.77]；宽0.10，净间隙0.08 | 0.105 → 0.205 → 0.385 → 0.565 → 0.745 | 地面→A→B→C→D，柱顶落点距后缘25 mm；第一段参考碰撞 |
| stairs | 台阶绝对高度0.10/0.20/0.30，踏面深0.15；x范围[0.12,0.27]、[0.27,0.42]、[0.42,0.57] | 0.095 → 0.245 → 0.395 → 0.545 | 地面→第一级→第二级→第三级；级高来自仿真默认stair10cm SDF |

公共参数：y=0.10，支撑平台横向范围[-0.25,0.25]，栅格分辨率0.005，足端球半径0.019，每次摆动0.3 s。参考抬脚高度0.085，时间缩放阈值0.20 s。优化器15控制点、60目标采样点、每原始段配置4个固定分片，峰值净空参数0.005，接触附近净空由平滑包络归零。

起落位置的 z 由物理高程地图吸附。图示/CSV中的 z 为“足端接触高度参数”，等于碰撞球心高度减半径；球心为 `[x,y,z+0.019]`。它不是球与棱边接触时唯一的实际接触点。

参考曲线在摆动中点满足：

`z(T/2) = max(z_start,z_goal) + min(1,T/swing_time_scale) * swing_height`。

这是曲线高度，不是中间控制点高度。更高/更低的中间控制点只用于确保曲线满足该插值条件。

### 方法名称

| CSV method | 含义 | 可比较内容 |
|---|---|---|
| reference | 生产高度样条，测试层嵌入起落点之间XY | 碰撞风险和优化修正；参考XY构造与优化器固定XY拟合流程存在区别 |
| Bezier | 用Bézier凸包构造避障约束得到的QP输出 | 与MINVO保持同一地形、目标和固定XY走廊比较 |
| MINVO | 用MINVO凸包构造约束的QP输出；接触端段仍使用Bézier处理 | 优化方法输出，不是说每一段约束都使用MINVO |
| MINVO_geometry | 不包含虚拟跨越带，只对物理地图规划 | 仅pillars存在，用于区分几何避障与额外跨柱高度策略 |

pillars 的 crossing_bands 是柱间净空区域中的**虚拟高度策略**，要求相应区域足底高度不低于0.06，物理高程图仍保留真实狭缝。Bezier与MINVO组采用同一策略，geometry组不采用。当前geometry组也未下探到柱顶以下，因此结果不能证明额外策略的相对收益。

## 3. 数据文件含义

### 3.1 每个场景目录 `data/<scene>/`

| 文件 | 一行代表什么 | 用途与注意事项 |
|---|---|---|
| config.yaml | 本次输入快照 | 复现配置与核对旧数据；优先于当前源码config |
| map.csv | 一个栅格中心，字段x/y/z | 真实float高程层；没有垂直立面内部点，绘图立面是从高程边界构建 |
| trajectories.csv | 一个swing、method、时间t上的解析样条值 | 画轨迹/速度/加速度；每条曲线601点，包含端点 |
| hulls.csv | 一个原始多项式段、一个基下的一个包络顶点 | 字段swing/method/basis/span/start/end/vertex/x/y/z；同段同曲线比较用 |
| spline_controls.csv | 原始B样条的一个控制点 | index、x/y/z_minus_radius；该历史字段名表示球心减半径，即上文的z参数，不要再减一次半径 |
| knots.csv | 原始B样条的一个节点 | index/knot；与控制点一起确定次数、支撑区间、节点重数 |
| metrics.csv | 一次摆动、一种优化方法的评价 | 安全、QP修正量、耗时与跨越带测量 |
| smoothness.csv | 一条参考或优化曲线的连续性与峰值测量 | 4001点峰值测量，节点处解析两侧检查；包含reference行 |

hulls.csv 的method和basis是两个独立概念。例如method=MINVO,basis=Bezier与method=MINVO,basis=MINVO，是**同一条MINVO优化输出曲线**的两种包络。method=Bezier与method=MINVO则是**两次不同约束基的优化输出**，不能混为一谈。

### 3.2 `trajectories.csv` 字段

| 字段 | 含义 |
|---|---|
| swing | 场景内摆动编号，从0开始；每段时间都从0开始 |
| method | 轨迹来源，见方法表 |
| t | 本次摆动内的物理时间，单位s |
| x/y/z | 足端位置参数，单位m；z不包含球半径 |
| vz/az | 生产接口解析垂直速度/加速度，m/s、m/s²；不是位置数值差分 |
| surface_z | 当前位置地图插值高度 |
| required_z | 足端球对保守地图棱柱不相交所需的接触高度参数，不是简单surface_z |

画出的z−required_z是竖直安全裕度。负值表明违反该保守几何条件；它不是球体到障碍的欧氏最短距离。多个曲线使用同一时刻不保证XY完全一样，局部图足端圆按各自曲线位置放置。

### 3.3 `metrics.csv` 字段

| 字段 | 定义与论文使用方式 |
|---|---|
| valid | 本次结果是否同时通过求解、物理认证及适用的跨越带检查；1为通过 |
| certificate | 独立物理认证状态：0=ProvenSafe、1=CollisionDetected、2=Unknown |
| min_clearance | 输出曲线2001个样本的最小z−required_z；包含接触端点，因此安全轨迹通常最小值为0 |
| reference_clearance | 原始reference的1001样本最小球体竖直净空，负值揭示参考违反保守几何条件 |
| endpoint_error | 输出起终点与指定起落位置的最大三维误差 |
| objective | 参考拟合后控制点修正量的二次代价，非总能耗；值为0可能表示拟合曲线无需修正 |
| planning_ms | 对optimizeSwingTrajectory调用计时：包括拟合、内部碰撞检查、QP、内部输出认证等；不含CSV/绘图与调用后的再次物理认证 |
| gap_min_bottom | 2001样本中落入任一crossing_band的最小z；无跨越带或该段没进入带时为NaN |
| crossing_violation | 采样中最大的band_height−z，非负；0表示没有采样违约。连续接受仍依靠虚拟模型认证 |
| reference_certificate | 对原始reference的生产认证结果；Unknown不等于安全，也不等于没有碰撞 |

安全认证来自保守棱柱与凸包/球体分离，再对不确定段细分；稠密采样本身不能证明连续时间安全。当前CollisionDetected见证检查主要识别接触高度曲线穿过插值高程，球体棱边碰撞可表现为Unknown；因此单独增加名义实体方柱的球体相交采样见证。

约1e-17量级的负净空属于接触点浮点误差，不能解释为实际穿透。ProvenSafe针对指定地图、足端模型和数值容差，不包括跟踪误差与建图误差。

### 3.4 `smoothness.csv` 字段

| 字段 | 含义 |
|---|---|
| min_internal_continuity | 根据五次样条内部节点最大重数计算的最小连续阶数；本批为4，即C4 |
| max_speed/max_acceleration | 4001个样本上三维速度/加速度的范数峰值，非仅垂直分量；不是连续上界证书 |
| max_position_gap/max_velocity_gap/max_acceleration_gap | 内部节点两侧t±T·1e-9的解析值差的最大范数；两时刻有间隔，因此差值不必严格为零 |
| lift_off_vz/touch_down_vz | 起落点垂直速度 |
| lift_off_acceleration/touch_down_acceleration | 起落点三维加速度范数 |

“内部C4连续”与“满足硬件速度/加速度上限”是不同结论。也不能推导支撑相接触切换连续：reference保留+0.04/-0.04 m/s起落速度，直接接上静止支撑或另一段摆动会涉及速度切换，当前没有验证接触冲击动力学。

### 3.5 `data/` 汇总数据

| 文件 | 含义与用途 |
|---|---|
| validation.csv | check_scenes.py复查端点、中点、连续性、认证、名义方柱碰撞见证后的场景级摘要；峰值取全部方法/摆动中最大值 |
| hull_metrics.csv | plot_scenes.py计算的同一MINVO输出、各摆动两种基的原始分段XZ凸包面积之和，单位m²；重叠部分重复计入 |
| single_swing0_MINVO_local_envelopes.csv | 单障碍同一MINVO输出的逐段B样条/Bézier/MINVO包络面积、采样曲线凸包面积、面积比；原始段，不是QP细分段 |
| single_endpoint_search.csv | 两轮起落点试跑中55组有效且reference碰撞的候选，按sum_ratio升序；不是随机独立试验或预先固定的测试集 |
| pillars_swing0_MINVO_local_envelopes.csv | 前一版局部包络脚本保留的柱体分析表；不作为当前仅single两图工作流的主要论文素材 |

validation中reference_nominal_sphere_margin_m由名义实体方柱到球心的距离减半径得到，负样本可证明该采样时刻确实相交。reference_grid_clearance_m是保守栅格的竖直安全裕度，两者定义不同，数值不可直接比较。

局部包络表：`*_area_m2`均为面积，乘1e6转换为mm²；`minvo_over_bezier<1`表示该段MINVO面积更小。sampled_curve_hull_area_m2只是采样点凸包面积，不能作为真实曲线凸包面积的精确值。原生B样条包络取该时间区间内具有支撑的p+1个原始控制点，不进行额外节点插入；与转换后基的差异应注明比较定义。

搜索表：sum_ratio=所有原始段MINVO面积之和/所有原始段Bézier面积之和；best_ratio为该候选的最小分段面积比；better_spans为MINVO面积更小的段数；bezier_area/minvo_area单位m²。只有成功求解且参考净空为负的候选被记录，不能用55条记录推导全部尝试的成功率。

## 6. 必须保留的结论边界与后续实验

1. **单障碍目前只有一个高度。** 若保留5.7.2“不同高度”，需补充多高度扫描；已有历史旧图不可混成同条件对比。
2. **局部优势是筛选后的结果。** 搜索55组候选并选出较好的端点，然后选面积比最小段；这是案例展示，不能当作无偏总体统计。完整图与全部段指标要同时提供。
3. **更小的投影包络不等于更优的QP输出。** 需分别比较修正代价、成功率、耗时和保守性；同一MINVO基不保证所有曲线所有投影都更小。
4. **认证范围限于几何模型。** 没有接入HOCBF，没有跟踪误差包络，没有未知地图补全，没有实机定位/足端姿态误差验证。
5. **连续性不代表硬件可执行。** 楼梯峰值接近187 m/s²。当前未引入已验证的速度/加速度硬上限或时间重分配；不能把本批曲线直接表述为满足机器人执行上限。
6. **不能把固定轨迹冻结称为剩余段在线重规划。** 5.6中触发、拼接连续性和恢复策略需单独的时序实验。
7. **耗时只作单次记录。** 如要论证实时性，需在固定硬件、固定数据和明确计时范围下多次运行，报告中位数、P95、最大值、QP和认证分项时间与失败情况；HOCBF耗时需另行采集。
8. **第5章标题含HOCBF不等于本批结果已覆盖。** 当前图表可作为规划层实验素材，5.5与5.7.6的跟踪部分仍缺实验。不能用规划净空代替真实跟踪安全裕度。
